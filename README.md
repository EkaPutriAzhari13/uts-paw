## Langkah singkat

1. Fork repo ini ke akun GitHub kamu.
2. Di fork: tab **Actions**, aktifkan workflow. Lalu **Settings → Pages → Source: GitHub Actions**.
3. Clone fork, kerjakan soal di folder `app/`:

   ```bash
   git clone https://github.com/USERNAME/uts-paw.git
   cd uts-paw/app
   npm install
   npm run dev
   ```

4. Cek perkiraan nilai kapan saja dengan `npm run cek` di folder `app/`.
5. Push ke `main`. Aplikasi tayang di `https://USERNAME.github.io/uts-paw/` dan ringkasan rubrik muncul di tab Actions (workflow **Build dan Deploy**).

Panduan lengkap beserta solusi kendala umum ada di halaman [Panduan](https://uts-paw.mhabibalgifari.web.id/panduan).

## Fitur

- 1. Navigasi Multi-halaman: perpindahan halaman beranda, koleksi, detail, statistik, dan tambah data dengan react router.
- 2. Pencarian data: melakukan pencarian data tanaman berdasarkan judul
- 3. Filtering data: dapat melakukan filter tanaman berdasarkan kategori
- 4. Pengujian unit: pengujian komponen dan fitur dengan Vitest dan React Testing Library

## Menjalankan secara lokal

cd app
npm install
npm run dev

## Konsep React yang dipakai

1. **Hooks Bawaan:**
   - Pemanfaatan useState dan useEffect
2. **Custom Hooks:**
   - Custom hook di folder src/hooks/
3. **Context API:**
   - KoleksiContext untuk global state management
4. **Routing:**
   - react-router-dom dengan rute utama, useParams, useNavigate, dan 404
5. **Komponen Modular:**
   - Pemisahan komponen di src/components/
6. **CSS dan Semantik:**
   - Responsive design dan HTML5 semantik
